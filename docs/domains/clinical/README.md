# Clinical 도메인

## 책임

현장 평가 프로토콜과 환자 상태·처치 기록의 구조와 이력을 관리합니다.

## 포함

- 버전이 있는 임상 프로토콜 정의
- 환자 상태, 활력징후, 의식, 처치와 보충 평가
- 현재 환자 요약과 임상 타임라인
- 정정과 재평가 이력

## 제외

- 병원 후보 검색과 목적지 선택
- 병원의 수락·거절 결정
- 구급차 위치와 ETA

## 핵심 계약

- 필수 항목은 값 또는 명시적인 미확인·거부 상태를 가집니다.
- 제출된 임상 기록은 덮어쓰지 않고 새 기록으로 정정합니다.
- 임상 시각과 서버 수신 시각을 구분합니다.
- 승인되지 않은 자동 임상 판단을 추가하지 않습니다.
