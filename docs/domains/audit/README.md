# Audit 도메인

## 책임

보안과 핵심 업무 행위의 확인 가능한 감사 이력을 보존합니다.

## 포함

- 행위자, 조직, 행위, 대상과 서버 시각
- 상태 변경 전후 또는 업무 이벤트
- 필수 사유가 있는 명령의 사유
- 보안·업무 감사 조회 기반

## 제외

- 애플리케이션 디버그 로그
- 도메인 현재 상태의 원본
- 실제 인증정보와 Secret 저장

## 핵심 계약

- 감사 이력은 임의로 덮어쓰거나 삭제하지 않습니다.
- 보안 시각은 신뢰 가능한 서버 시각을 사용합니다.
- 실제 환자정보, 토큰, 비밀번호와 가입 코드를 기록하지 않습니다.
- 감사 대상과 보존 정책은 승인된 기능 명세를 따릅니다.
