# Location 도메인

## 책임

활성 이송의 최신 위치, 위치 신선도와 지도·거리 계산 연동을 관리합니다.

## 포함

- 요청별 마지막 위치
- 최신·오래됨 상태와 마지막 수신 시각
- 거리와 ETA 외부 지도 어댑터
- 목적지 병원 위치 전달

## 제외

- 이동 경로 전체 저장
- 병원 후보·목적지 결정
- 임상정보와 인계 완료

## 핵심 계약

- 서버는 경로 이력이 아니라 최신 위치만 유지합니다.
- 정확한 위치는 요청 소유자와 현재 목적지 병원에만 제공합니다.
- 기본 기준을 넘긴 위치는 오류가 아닌 `STALE` 상태입니다.
- 지도 서비스 실패는 임상 요청 흐름을 중단하지 않습니다.
