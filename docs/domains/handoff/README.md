# Handoff 도메인

## 책임

구급대원의 인계 완료 요청과 목적지 병원의 확인으로 이송을 종결합니다.

## 포함

- 구급대원 인계 완료 요청
- 현재 목적지 병원의 완료 확인
- 요청·확인 시각과 행위자 기록
- 완료에 따른 활성 요청 종료

## 제외

- 목적지 선택과 변경
- 병원 수락·거절
- 외부 법정 서명 절차

## 핵심 계약

- 완료는 구급대원 요청과 현재 목적지 병원 확인이 모두 필요합니다.
- 목적지가 아닌 병원은 완료를 확인할 수 없습니다.
- 완료 후 활성 카드와 실시간 전달을 종료합니다.
- 저장된 임상정보와 감사 이력은 삭제하지 않습니다.
