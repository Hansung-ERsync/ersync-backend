# Invitation 도메인

## 책임

승인된 조직과 역할에 계정을 연결하는 일회성 가입 코드를 관리합니다.

## 포함

- 조직·역할에 결합된 가입 코드 발급
- 유효기간, 사용, 만료와 조기 폐기
- 코드 상태와 발급·사용 이력

## 제외

- 로그인과 토큰 발급
- 조직 자체의 등록·수정
- 가입 이후 계정 권한 변경

## 핵심 계약

- 가입 코드는 평문으로 저장하지 않습니다.
- 코드는 한 번만 사용할 수 있고 조직과 대상 역할에 묶입니다.
- 사용, 만료와 폐기 이벤트는 감사 대상입니다.
- 실제 코드는 로그, 오류 응답과 문서 예시에 기록하지 않습니다.
