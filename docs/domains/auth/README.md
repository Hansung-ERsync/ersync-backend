# Auth 도메인

## 책임

계정 인증과 인가에 필요한 사용자 신원을 제공하고 인증 수명주기를 관리합니다.

## 포함

- 로그인과 토큰 발급·재발급·폐기
- 계정 활성 상태 확인
- 인증된 사용자, 역할과 조직 컨텍스트 제공

## 제외

- 조직 등록과 상태 관리
- 가입 코드 발급·사용 정책
- 기능별 세부 권한과 소유권 정책

## 핵심 계약

- 권한 판단은 인증된 계정의 역할과 조직을 기준으로 합니다.
- 클라이언트가 보낸 계정·조직 ID를 권한 근거로 신뢰하지 않습니다.
- 비밀번호와 토큰은 로그, 오류 응답과 문서 예시에 기록하지 않습니다.
- 역할별 기능 권한은 각 기능 명세에서 확정합니다.
