# Transport 도메인

## 책임

응급환자 이송 요청의 생성부터 병원 검색, 응답, 목적지와 취소 상태를 관리합니다.

## 포함

- 이송 요청과 검색 회차
- 병원 후보 검색과 수락·거절·철회 이력
- 목적지 선택·변경과 이송 취소
- 요청 상태 전이와 동시성 제어

## 제외

- 임상 항목의 정의와 기록 방식
- 실시간 위치 저장과 ETA 계산
- 인계 완료의 양측 확인

## 핵심 계약

- 여러 병원이 수락할 수 있지만 현재 목적지는 최대 한 곳입니다.
- 초기 병원 후보는 서버가 자동으로 선택합니다.
- 이력은 삭제하지 않고 상태와 종료 시각으로 활성 노출을 제어합니다.
- 취소는 허용된 시점의 사유 필수 종결 상태입니다.
