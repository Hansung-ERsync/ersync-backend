# Notification 도메인

## 책임

도메인 상태 변화를 권한 있는 앱과 웹 사용자에게 안정적으로 전달합니다.

## 포함

- 실시간 이벤트 전달
- 트랜잭션 아웃박스와 재전송
- 연결 복구와 갱신 신호
- 전달 지연과 실패 관측

## 제외

- 이송·병원 응답 상태의 원본 관리
- 푸시 메시지로 비즈니스 상태 확정
- 수신자의 기능별 접근 권한 결정

## 핵심 계약

- 실시간 이벤트는 상태 변경 힌트이며 서버 조회 결과가 기준입니다.
- 재연결한 클라이언트는 권한 있는 최신 상태를 다시 조회합니다.
- 이벤트 수신자는 각 도메인의 접근 정책을 따릅니다.
- 알림과 로그에 불필요한 임상정보와 정확한 위치를 포함하지 않습니다.
